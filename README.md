Hospital Management System

A desktop-based Hospital Management System developed using Java Swing, MySQL, and JDBC.

Project Overview

This project is designed to simplify basic hospital management activities through a user-friendly graphical interface. It allows users to register patients, view patient records, and update patient information. Patient details are stored and managed using a MySQL database.

Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE

Features

- Login interface
- Dashboard navigation
- Patient registration
- View patient records
- Edit patient details
- MySQL database connectivity
